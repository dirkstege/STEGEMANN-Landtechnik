# STEGEMANN Landtechnik for Ubuntu Touch

An unofficial Ubuntu Touch WebApp for STEGEMANN Landtechnik, based on the chayns website.

## About

STEGEMANN Landtechnik is a German company based in Billerbeck, Germany, specializing in agricultural, forestry and municipal machinery.

This application provides convenient access to the STEGEMANN Landtechnik chayns website on Ubuntu Touch smartphones.

## Features

- Direct access to the STEGEMANN Landtechnik chayns website
- Mobile-friendly WebApp interface
- Session cookie storage
- Integration with the Ubuntu Touch application launcher
- Dedicated STEGEMANN Landtechnik app icon

## Website

https://stegemann-landtechnik.chayns.site/

## Requirements

- Ubuntu Touch
- Internet connection

## Development

Built using Clickable and the Ubuntu Touch webapp-container.

Tested on Fairphone 4 running Ubuntu Touch.

## Build and Install

```bash
clickable build
clickable install
clickable launch
```
